## 💡 Key Takeaways

- 📝 Raw text must be cleaned before any ML model can use it
- ✂️ Tokenization is the first step of every NLP pipeline
- 🔡 Lowercasing + punctuation removal standardizes the text
- 🚫 Stop-word removal reduces noise but must be done carefully
- 🌱 Lemmatization reduces vocabulary without losing meaning
- ⚠️ Cleaning choices are never one-size-fits-all — always check task requirements
