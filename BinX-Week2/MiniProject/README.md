# 🚀 Mini Project — Week 2: Math Foundations & Exploratory Data Analysis

## 📌 Overview

During Week 2 of the **BinX AI & Machine Learning Internship Program**, I built a complete understanding of the mathematical foundations behind Machine Learning models and applied them through a full Exploratory Data Analysis (EDA) workflow.

### Topics Covered:

  - Median
  - Mode
- Measures of spread:
  - Range

# 📅 Day 3 — Linear Algebra for Machine Learning

### Topics Covered:

- Linear Algebra as the foundation of ML.
- Vectors.
- Matrices.
- Dot Product.
- Matrix Multiplication.
- Shape matching rules.

### What I Learned:

I learned how Machine Learning models represent data mathematically.

I understood that:

- A single data sample can be represented as a vector.
- A complete dataset can be represented as a matrix.

I also practiced understanding shape mismatch errors and how matrix dimensions affect ML operations.

# 📅 Day 5 — Exploratory Data Analysis (EDA) Part 2

## Correlation & Data Storytelling

### Topics Covered:

- Bivariate analysis.
- Scatter plots.
- Grouped box plots.
- Correlation matrix.
- Correlation heatmap.
- Pairplot.
- Data storytelling.

### What I Learned:

I learned how to discover relationships between variables and understand how features interact with each other.

I practiced using correlation analysis to identify strong relationships between numerical variables.

> Correlation does not mean causation.
