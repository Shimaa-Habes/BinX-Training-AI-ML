# 🧮 Day 3 — Linear Algebra for Machine Learning

## 📌 Overview

In this lesson, I learned the fundamental linear algebra concepts used in Machine Learning.

Linear algebra allows ML models to represent data, perform calculations, and generate predictions using vectors and matrices.

---

## 📚 Topics Covered

### 🔹 Vectors

A vector represents one data sample's features.

Example:

- Age
- Income
- Tenure

---

### 🔹 Matrices

A matrix represents a complete dataset.

- Rows → Samples
- Columns → Features

Shape:

(samples, features)

---

### 🔹 Dot Product

The dot product combines features and weights to calculate a prediction.

Formula:

Prediction = Features · Weights + Bias

---

### 🔹 Matrix Multiplication

Matrix multiplication allows models to calculate predictions for multiple samples at once.

Shape rule:

(m × n) @ (n × p) = (m × p)
